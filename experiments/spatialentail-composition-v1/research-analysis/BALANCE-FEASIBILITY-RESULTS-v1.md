# Balance Feasibility Results v1

## Verdict

This is a bounded availability check, not a production dataset. Equal task/contract counts are achievable by retaining complete three-contract menu bundles. The run does not establish the previously suggested 60/20/20 mix, all spatially feasible cells, final split quotas, or sufficient independent structures for production.

No prior dataset was changed. No seal, training files or benchmark split was created. All inputs are development examples; these depth-9/10 families are not held-out tests.

## Fixed Attempt Budget

Seed 20261030; 80 stories and 240 base questions; no retries or replacements. 30 depth controls, 24 random-world stories, 16 random-atom stories and 10 targeted controls. At most five menus per base, one per feasible displayed-possible count, with all three contracts and both styles. Solver timeout is 5000 ms per call.

Admitted stories: 80; admitted source families: 55; menu bundles: 453; views per style: 1359. The menu inventory is deliberately coverage-seeking, not a proposed exposure mix.

The 80 scheduled stories have 55 source-family IDs. In particular the 30 controlled-depth stories belong to only six source families (three per depth band). Related depth variants are not independent families. This run checks existing generator capacity, not a new diverse construction library.

## Structural Impossibilities and Coupling

- Unique never returns a substantive multi-letter answer.
- A determinate Direction or Count cannot supply substantive G2-G4 under any contract.
- Inconsistent premises yield E in all contracts.
- Consistent Selection with no possible match yields E / F / F.
- A unique answer omitted from a menu yields F / F / F.
- A covered unique answer yields the same substantive letter in all three contracts.
- Every multi-letter Listed or Exhaustive answer implies Unique E in that same bundle.
- A nonempty possible set larger than four cannot be fully covered: Exhaustive is F.
- Under the current depth definition, ambiguous Direction cannot fill a numeric-depth quota.
- Count zero is a substantive value, not an empty possible-answer set.

Therefore semantic mixtures cannot be tuned independently per contract while preserving the pivot's complete bundles. In particular the earlier uniform 60/20/20 suggestion is not a feasible-cell specification and should not be adopted. For example, 80% substantive Unique answers implies at least 80% substantive single-letter answers in each other contract. Uniform G1-G4 proportions in those contracts would conflict with that target. Quotas must be solved jointly over bundle semantic types, not chosen independently for the nine groups.

## Concrete Coverage Gaps

1. **Unique Selection needs explicit substantive coverage.** Only 20/70 selected Unique Selection views are substantive; 50/70 are E/F. Equal task totals alone do not fix this.
2. **The naive topology filter loses an available depth cell.** There are two substantive Unique Selection bases at requested depth 2 in the full candidate pool, but none in the diagnostic subset. The filter can retain a different semantic case with the same coarse topology. Production selection must preserve depth and semantic coverage jointly; one global representative per topology is not an approved policy.
3. **Exhaustive Direction with four possible answers is unobserved.** Listed Direction does reach four displayed possibilities, but that does not demonstrate a full possible set of exactly four. Establish realizability and certificate support before assigning this cell a quota.
4. **Invariant Count with changing member identities is unobserved.** The admitted Count cases include 43 fixed-membership invariants, 31 variable counts and six inconsistent cases. This does not prove the missing subtype impossible.
5. **Coverage is thin in 72 cells.** Each has only one underlying base. More menu permutations cannot supply independent examples.
6. **Deep constructions remain concentrated.** The 30 controlled stories belong to six generator families. Topology counts include attached branch variation and are not a substitute for varied reasoning structures.
7. **The inherited certificate boundary was not exercised.** Zero rejections in this sample does not establish support for every atomic input; the documented indirect-coincidence case remains outside the shared certificate builder.

## Rejections

No bases rejected.

Certificate failures are not semantic impossibility. The run keeps their solver-observed cells separately from admitted cells. Previously documented unsupported proof forms remain a limitation even if this sample does not hit them.

## Next Approval Decision

Do not scale the current inventory directly into training. First use the observed gaps to specify needed generator constructions, then propose quotas over complete bundles with minimum distinct bases and structural/source caps. Production family splitting, final sample size and per-cell minima remain unapproved. No additional sampling is implied by this report.
